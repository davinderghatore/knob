Knob

Install
1. Quit Knob from its menu bar icon if it is running.
2. Open Knob-Install.pkg and follow the steps. It asks for your password
   because it adds Knob's audio device to the system.
3. Sound stops for a moment while the Mac's audio service restarts.
4. Open Knob from Applications. The first time you turn it on, allow audio
   access when macOS asks.

Uninstall
Quit Knob from its menu bar icon, then open Uninstall-Knob.command.
