Knob

Install
1. Quit Knob from its menu bar icon if it is running.
2. Open Knob-Install.pkg and follow the steps. It asks for your password
   because it adds Knob's audio device to the system.
   If macOS says it can't verify the installer, open System Settings,
   go to Privacy & Security, and click Open Anyway next to Knob-Install.pkg.
3. Sound stops for a moment while the Mac's audio service restarts.
4. Knob opens by itself and its icon appears in the menu bar. The first time
   you turn it on, allow audio access when macOS asks.

Updates
Knob updates itself. It checks for new versions when it starts and every few
hours, then installs them in the background and reopens. You never need to
download Knob again. An update that changes Knob's audio device asks for your
password once.

Uninstall
Quit Knob from its menu bar icon, then open Uninstall-Knob.command.
